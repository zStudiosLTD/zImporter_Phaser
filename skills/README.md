# zImporter skills

Short Markdown guides that teach an AI tool to use this package correctly: Phaser.

- **In zStudio:** Help → AI Skill Libraries → Add Library Folder, and pick this folder.
- **In any other AI tool:** point it at this folder. After `npm install` it is at `node_modules/zimporter-phaser/skills/`.

Each file starts with a `name` and `description` header so the tool knows when to load it.
